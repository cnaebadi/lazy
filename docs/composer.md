# composer (`c`)

prefix: **c** · needs: `composer`

| command | does |
|---------|------|
| `cins` | `composer install` |
| `cup` | `composer update` |
| `creq laravel/sanctum` | `composer require laravel/sanctum` |
| `cdu` | `composer dump-autoload` |
| `crs test` | `composer run-script test` |

extra flags pass through.

**note:** `crs` not `crun` — Linux has `/usr/bin/crun`.
